# 🤖 Sistema de Chatbot WhatsApp com API

Sistema completo para gerenciamento de chatbot WhatsApp com geração de chaves API.

## 🚀 Funcionalidades

- ✅ Conexão com WhatsApp via API
- 🔑 Geração de App Key e Auth Key
- 💬 Chatbot inteligente com respostas automáticas
- 📊 Dashboard de estatísticas
- 🔐 Gerenciamento seguro de chaves
- 📱 Interface responsiva
- 💾 Armazenamento local
